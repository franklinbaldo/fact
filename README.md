# fact

A conservative profile over [OKF](https://github.com/franklinbaldo/okf-parser) v0.2 — naming its atom a
`fact` and its scope a `context`, with self-describing type specifications, stable fact identity, no
reserved filenames, and a declared adapter boundary for foreign specifications.

See [RFC 0009](rfcs/0009-fact-profile.md) for the founding proposal.
